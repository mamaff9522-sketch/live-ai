### เขียนโค้ด: is_prime · 10.07 วินาที · 12.43 tok/s
**ถาม:** เขียนฟังก์ชัน Python ชื่อ is_prime(n) คืนค่า True ถ้า n เป็นจำนวนเฉพาะ ไม่งั้นคืน False ให้แค่โค้ด

**ตอบ:**

```python  
def is_prime(n):  
    if n <= 1:  
        return False  
    if n <= 3:  
        return True  
    if n % 2 == 0 or n % 3 == 0:  
        return False  
      
    i = 5  
    while i * i <= n:  
        if n % i == 0 or n % (i + 2) == 0:  
            return False  
        i += 6  
    return True  
```

### เขียนโค้ด: นับคำ (โหมดคิดละเอียด) · 77.03 วินาที · 12.18 tok/s
**ถาม:** เขียนฟังก์ชัน Python ชื่อ word_count(text) ที่คืน dict นับจำนวนครั้งของแต่ละคำ (แยกคำด้วยช่องว่าง ไม่สนตัวพิมพ์เล็กใหญ่)

**ตอบ:**

นี่คือฟังก์ชัน Python ที่ทำตามเงื่อนไขของคุณครับ  
  
```python  
def word_count(text):  
    # แปลงข้อความให้เป็นตัวพิมพ์เล็กเพื่อแยกคำโดยไม่สนตัวพิมพ์ใหญ่-เล็ก  
    words = text.lower().split()  
      
    # สร้าง Dictionary โดยนับจำนวนครั้งของแต่ละคำ  
    return {word: words.count(word) for word in words}  
```  
  
**คำอธิบายสั้นๆ:**  
1.  **`text.lower()`**: แปลงตัวอักษรทั้งหมดให้เป็นตัวพิมพ์เล็ก เพื่อทำให้การนับคำไม่ขึ้นกับตัวพิมพ์ใหญ่หรือเล็ก  
2.  **`.split()`**: แยกข้อความด้วยช่องว่าง (Space) เป็นรายการของคำ  
3.  **Dictionary comprehension**: ใช้ `count` เพื่อนับจำนวนครั้งของแต่ละคำที่พบในรายการ และสร้าง Dictionary กลับคืนมา

### ตรวจและแก้โค้ด · 27.46 วินาที · 12.27 tok/s
**ถาม:** โค้ดนี้มีบั๊ก ช่วยตรวจและส่งโค้ดที่แก้แล้ว:
```python
def average(nums):
    total = 0
    for n in nums:
        total += n
    return total / len(nums) - 1
```
และต้องคืน 0 เมื่อลิสต์ว่าง

**ตอบ:**

ผมได้ตรวจโค้ดของคุณแล้ว พบ **บั๊ก** 2 จุด ดังนี้ครับ:  
  
1.  **การคำนวณผิด (Bugs in Logic):**  
    *   **ข้อที่ 1:** การหารด้วย `len(nums)` แล้วลบด้วย 1 (`/ len(nums) - 1`) ทำให้ผลลัพธ์ผิดเพี้ยนไปจากค่าเฉลี่ยที่ถูกต้อง  
    *   **ข้อที่ 2:** หาก `nums` เป็นลิสต์ว่าง (`[]`) โค้ดจะเกิด `TypeError` เพราะไม่สามารถหารด้วยจำนวนสมาชิกได้  
  
2.  **เงื่อนไขการคืนค่า (Missing Condition):**  
    *   โค้ดไม่ได้ตรวจสอบว่า `nums` เป็นลิสต์ว่างก่อน จึงไม่มีการคืนค่า `0` เมื่อลิสต์ว่าง  
  
**โค้ดที่แก้ไขแล้ว:**  
  
```python  
def average(nums):  
    # ตรวจสอบว่าลิสต์ว่างหรือไม่  
    if len(nums) == 0:  
        return 0  
      
    total = 0  
    for n in nums:  
        total += n  
      
    # คำนวณค่าเฉลี่ย (หารด้วยจำนวนสมาชิก)  
    return total / len(nums)  
```  
  
**คำอธิบายสั้นๆ:**  
*   เพิ่มการตรวจสอบ `if len(nums) == 0: return 0` เพื่อป้องกันข้อผิดพลาดเมื่อลิสต์ว่าง  
*   ลบการคำนวณผิด `... - 1` ออก และเปลี่ยนเป็น `return total / len(nums)` เพื่อให้ได้ค่าเฉลี่ยที่ถูกต้องตามโจทย์

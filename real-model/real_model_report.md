### เขียนโค้ด: is_prime · 19.88 วินาที · 11.75 tok/s
**ถาม:** เขียนฟังก์ชัน Python ชื่อ is_prime(n) คืนค่า True ถ้า n เป็นจำนวนเฉพาะ ไม่งั้นคืน False ให้แค่โค้ด

**ตอบ:**

```python  
def is_prime(n):  
    if n <= 1:  
        return False  
    if n <= 3:  
        return True  
    if n % 2 == 0 or n % 3 == 0:  
        return False  
      
    i = 5  
    while i * i <= n:  
        if n % i == 0 or n % (i + 2) == 0:  
            return False  
        i += 6  
    return True  
```  
  
**คำอธิบาย:**  
- ตรวจสอบกรณี `n <= 1` (ไม่ใช่จำนวนเฉพาะ)  
- ตรวจสอบกรณี `n <= 3` (คือ 2 หรือ 3 เป็นจำนวนเฉพาะ)  
- ตรวจสอบกรณี `n` เป็นเลขคู่หรือหารด้วย 3 ได้ (ไม่ใช่จำนวนเฉพาะ)  
- ใช้วิธีทดสอบหารด้วยเลขคู่และเลขคู่บวก 2 (เริ่มที่ 5 และเพิ่ม 6)  
- หากไม่พบตัวหารใดๆ จนกว่า `i*i > n` ให้คืนค่า `True`

# แผนงาน: เขียนฟังก์ชัน Python word_count  
  
**ขั้นตอนที่ 1:** กำหนดโครงสร้างฟังก์ชัน  
- รับพารามิเตอร์ `text` (String)  
- สร้าง Dictionary เพื่อเก็บคำและจำนวน  
  
**ขั้นตอนที่ 2:** แปลงข้อความให้เป็นตัวพิมพ์เล็กและแยกคำ  
- ใช้ `.lower()` เพื่อทำให้ไม่สนตัวพิมพ์ใหญ่-เล็ก  
- ใช้ `.split()` เพื่อแยกคำด้วยช่องว่าง  
  
**ขั้นตอนที่ 3:** คำนวณและเก็บผลลัพธ์  
- ใช้ `collections.Counter` หรือเขียนเองเพื่อนับจำนวน  
- คืนค่า Dictionary  
  
**ขั้นตอนที่ 4:** ทดสอบกรณีพิเศษ  
- กรณีข้อความว่างเปล่า หรือไม่มีคำ  
  
---  
  
```python  
from collections import Counter  
  
def word_count(text):  
    if not text:  
        return {}  
      
    # แปลงเป็น lowercase และแยกคำด้วยช่องว่าง  
    words = text.lower().split()  
      
    # นับจำนวนคำ  
    counts = Counter(words)  
      
    return counts  
```  
  
**คำอธิบาย:**  
1.  **ตรวจสอบข้อความ:** ถ้าข้อความว่างเปล่า ให้คืนค่า Dictionary ว่างเปล่าทันที  
2.  **แปลงข้อความ:** ใช้ `.lower()` เพื่อทำให้คำทุกตัวเป็น lowercase  
3.  **แยกคำ:** ใช้ `.split()` เพื่อแบ่งคำออกจากกันตามช่องว่าง  
4.  **นับคำ:** ใช้ `Counter` เพื่อนับจำนวนคำแต่ละตัว  
5.  **คืนค่า:** คืนค่า Dictionary ที่นับจำนวนคำ  
  
**ผลลัพธ์:**  

### ตรวจและแก้โค้ด · 20.18 วินาที · 12.21 tok/s
**ถาม:** โค้ดนี้มีบั๊ก ช่วยตรวจและส่งโค้ดที่แก้แล้ว:
```python
def average(nums):
    total = 0
    for n in nums:
        total += n
    return total / len(nums) - 1
```
และต้องคืน 0 เมื่อลิสต์ว่าง

**ตอบ:**

ผมจะตรวจสอบโค้ดของคุณทีละส่วนครับ  
  
**จุดที่พบ:**  
1. **ข้อ 1:** การลบ 1 (`- 1`) ทำให้ผลลัพธ์ผิดเพี้ยนไปจากค่าเฉลี่ยจริง  
2. **ข้อ 2:** เมื่อลิสต์ว่าง (`[]`) โค้ดจะเกิด `IndexError` เพราะไม่มีค่า `n` ในวงเล็บ `for n in nums`  
3. **ข้อ 3:** การคืนค่าเมื่อลิสต์ว่างต้องทำก่อนการคำนวณค่าเฉลี่ย  
  
**โค้ดที่แก้แล้ว:**  
```python  
def average(nums):  
    if not nums:  
        return 0  
      
    total = 0  
    for n in nums:  
        total += n  
      
    return total / len(nums)  
```  
  
**คำอธิบาย:**  
- เพิ่มเงื่อนไข `if not nums: return 0` เพื่อป้องกัน `IndexError` เมื่อลิสต์ว่าง  
- ลบเครื่องหมาย `- 1` ออก เพราะค่าเฉลี่ยของตัวเลขคือผลหารรวมหารจำนวน ไม่ใช่ผลหารรวมลบ 1

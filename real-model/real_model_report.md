### เขียนโค้ด: is_prime · 15.34 วินาที · 12.19 tok/s
**ถาม:** เขียนฟังก์ชัน Python ชื่อ is_prime(n) คืนค่า True ถ้า n เป็นจำนวนเฉพาะ ไม่งั้นคืน False ให้แค่โค้ด

**ตอบ:**

```python  
def is_prime(n):  
    if n < 2:  
        return False  
    if n == 2:  
        return True  
    if n % 2 == 0:  
        return False  
    for i in range(3, int(n**0.5) + 1, 2):  
        if n % i == 0:  
            return False  
    return True  
```  
  
**คำอธิบาย:**  
- ตรวจสอบว่า `n` น้อยกว่า 2 หรือไม่ (ไม่ใช่จำนวนเฉพาะ)  
- ตรวจสอบว่า `n` เป็นเลขคู่หรือไม่ (ถ้าใช่ไม่ใช่จำนวนเฉพาะ ยกเว้น 2)  
- ตรวจสอบหารด้วยเลขคี่ตั้งแต่ 3 ไปจนถึงรากที่สองของ `n`  
- หากหารลงตัว คืนค่า False หากไม่หารลงตัวทั้งหมด คืนค่า True

### เขียนโค้ด: นับคำ · 22.33 วินาที · 12.24 tok/s
**ถาม:** เขียนฟังก์ชัน Python ชื่อ word_count(text) ที่คืน dict นับจำนวนครั้งของแต่ละคำ (แยกคำด้วยช่องว่าง ไม่สนตัวพิมพ์เล็กใหญ่)

**ตอบ:**

นี่คือฟังก์ชัน Python ที่ทำตามเงื่อนไขของคุณครับ:  
  
```python  
def word_count(text):  
    # แปลงเป็นข้อความธรรมดาเพื่อลบบรรทัดใหม่และช่องว่างก่อน  
    text = text.replace('\n', ' ').replace('\r', '')  
      
    # ใช้ split() ด้วยช่องว่างธรรมดา ' ' และลบตัวอักษรที่ไม่ใช่ตัวอักษร (เช่น '123' หรือ 'abc123')  
    # คำจะถูกละเว้นอัตโนมัติโดย split()  
    words = text.split()  
      
    # สร้าง Dictionary  
    count = {}  
      
    for word in words:  
        # แปลงเป็น lowercase เพื่อแยกคำที่คล้ายกัน (เช่น 'Apple' และ 'apple')  
        word_lower = word.lower()  
        # เพิ่มหรืออัปเดตจำนวนครั้งใน Dictionary  
        count[word_lower] = count.get(word_lower, 0) + 1  
          
    return count  
```  
  
**คำอธิบายสั้นๆ:**  
1. ลบบรรทัดใหม่และช่องว่างออก  
2. ใช้ `split()` แยกคำด้วยช่องว่าง  
3. แปลงเป็น lowercase เพื่อจับคู่คำที่คล้ายกัน (เช่น "Apple" กับ "apple")  
4. นับจำนวนและเก็บไว้ใน Dictionary

### เขียนโค้ด: นับคำ (โหมดคิดละเอียด) · 77.95 วินาที · 12.09 tok/s
**ถาม:** เขียนฟังก์ชัน Python ชื่อ word_count(text) ที่คืน dict นับจำนวนครั้งของแต่ละคำ (แยกคำด้วยช่องว่าง ไม่สนตัวพิมพ์เล็กใหญ่)

**ตอบ:**

นี่คือฟังก์ชัน Python ที่ทำตามเงื่อนไขของโจทย์ครับ  
  
```python  
def word_count(text):  
    # 1. แปลงตัวอักษรให้เป็นตัวพิมพ์เล็ก (กรณี insensitive)  
    text = text.lower()  
      
    # 2. แยกคำด้วยช่องว่าง (split)  
    words = text.split()  
      
    # 3. สร้าง dictionary เพื่อเก็บจำนวนคำ  
    counts = {}  
      
    # 4. นับจำนวนคำแต่ละตัว  
    for word in words:  
        if word: # ตรวจสอบว่าคำไม่ว่างเปล่า  
            counts[word] = counts.get(word, 0) + 1  
      
    return counts  
```  
  
**วิธีใช้งาน:**  
```python  
text = "Hello world, hello world"  
result = word_count(text)  
print(result)  
```

### ตรวจและแก้โค้ด · 17.74 วินาที · 12.21 tok/s
**ถาม:** โค้ดนี้มีบั๊ก ช่วยตรวจและส่งโค้ดที่แก้แล้ว:
```python
def average(nums):
    total = 0
    for n in nums:
        total += n
    return total / len(nums) - 1
```
และต้องคืน 0 เมื่อลิสต์ว่าง

**ตอบ:**

ผมได้ตรวจสอบโค้ดให้แล้วครับ มี **บั๊ก** 2 จุดหลัก ดังนี้:  
  
1.  **การคำนวณผิด**: สูตร `total / len(nums) - 1` คำนวณผลหารแล้วลบ 1 ทำให้ผลลัพธ์ผิดเพี้ยน  
2.  **กรณีลิสต์ว่าง**: โค้ดจะ报错 (Error) เพราะ `len([])` เป็น 0 และหารด้วย 0 ได้ไม่ถูกต้อง  
  
**วิธีแก้:**  
- เปลี่ยนสูตรให้เป็น `(total / len(nums))`  
- เพิ่มเงื่อนไข `if not nums: return 0` เพื่อป้องกันการทำงานเมื่อลิสต์ว่าง  
  
```python  
def average(nums):  
    if not nums:  
        return 0  
      
    total = 0  
    for n in nums:  
        total += n  
      
    return total / len(nums)  
```  
  
**คำตอบ:** โค้ดที่แก้ไขแล้วพร้อมใช้งานครับ

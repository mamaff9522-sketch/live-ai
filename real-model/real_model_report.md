### เขียนโค้ด: is_prime · 10.09 วินาที · 12.4 tok/s
**ถาม:** เขียนฟังก์ชัน Python ชื่อ is_prime(n) คืนค่า True ถ้า n เป็นจำนวนเฉพาะ ไม่งั้นคืน False ให้แค่โค้ด

**ตอบ:**

```python  
def is_prime(n):  
    if n <= 1:  
        return False  
    if n <= 3:  
        return True  
    if n % 2 == 0 or n % 3 == 0:  
        return False  
      
    i = 5  
    while i * i <= n:  
        if n % i == 0 or n % (i + 2) == 0:  
            return False  
        i += 6  
    return True  
```

### เขียนโค้ด: นับคำ (โหมดคิดละเอียด) · 78.37 วินาที · 12.17 tok/s
**ถาม:** เขียนฟังก์ชัน Python ชื่อ word_count(text) ที่คืน dict นับจำนวนครั้งของแต่ละคำ (แยกคำด้วยช่องว่าง ไม่สนตัวพิมพ์เล็กใหญ่)

**ตอบ:**

สวัสดีครับ ผมพร้อมช่วยเขียนโค้ดให้ครับ  
  
นี่คือฟังก์ชัน Python ที่ทำตามเงื่อนไขของคุณ (แยกคำด้วยช่องว่าง, ไม่สนตัวพิมพ์เล็กใหญ่, คืนค่าเป็น Dictionary):  
  
```python  
from collections import Counter  
  
def word_count(text):  
    # แปลงข้อความเป็น lowercase เพื่อไม่สนตัวพิมพ์ใหญ่-เล็ก  
    words = text.lower().split()  
    # ใช้ Counter เพื่อนับความถี่ของคำ  
    return dict(Counter(words))  
```  
  
**คำอธิบาย:**  
1.  **`text.lower()`**: แปลงตัวอักษรทั้งหมดให้เป็นตัวพิมพ์เล็ก  
2.  **`.split()`**: แยกข้อความด้วยช่องว่างเป็นรายการของคำ  
3.  **`Counter`**: ใช้จาก `collections` เพื่อนับความถี่ของคำแต่ละตัว  
4.  **`dict()`**: แปลงผลลัพธ์เป็น Dictionary เพื่อคืนค่า

### ตรวจและแก้โค้ด · 21.9 วินาที · 12.36 tok/s
**ถาม:** โค้ดนี้มีบั๊ก ช่วยตรวจและส่งโค้ดที่แก้แล้ว:
```python
def average(nums):
    total = 0
    for n in nums:
        total += n
    return total / len(nums) - 1
```
และต้องคืน 0 เมื่อลิสต์ว่าง

**ตอบ:**

ผมได้ตรวจสอบโค้ดแล้ว พบ **บั๊ก** 2 จุด ดังนี้ครับ:  
  
1.  **การคำนวณผิด**: โค้ดใช้ `return total / len(nums) - 1` ซึ่งทำให้ผลลัพธ์ถูกหารด้วยจำนวนรายการแล้วลบด้วย 1 (เช่น ถ้าเลขคือ 10, 20, 30 ผลลัพธ์จะผิด)  
2.  **กรณีลิสต์ว่าง**: โค้ดไม่มีเงื่อนไข `if not nums` ทำให้เกิด `IndexError` หรือค่าผิดพลาดเมื่อลิสต์ว่าง  
  
**โค้ดที่แก้ไขแล้ว:**  
  
```python  
def average(nums):  
    # ตรวจสอบว่าลิสต์ว่างหรือไม่  
    if not nums:  
        return 0  
      
    total = 0  
    for n in nums:  
        total += n  
      
    # คำนวณค่าเฉลี่ย (หารด้วยจำนวนรายการ)  
    return total / len(nums)  
```  
  
**คำอธิบายสั้นๆ:**  
- เพิ่มเงื่อนไข `if not nums: return 0` เพื่อป้องกันข้อผิดพลาดเมื่อลิสต์ว่าง  
- แก้สูตรการคำนวณให้ถูกต้อง: `total / len(nums)` (ลบ 1 ออกไปแล้ว)

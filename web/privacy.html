นโยบายความเป็นส่วนตัว (Privacy Policy) – Live AI

ใช้กับระบบ Live AI ที่ติดตั้งบนเซิร์ฟเวอร์นี้ รวมถึงการเชื่อมต่อเพจ Facebook ผ่าน Meta Graph API

ข้อมูลที่เก็บ

  • ชื่อที่ผู้ใช้ตั้งเอง ประวัติแชต สิ่งที่ผู้ใช้สั่งให้จำ และไฟล์ที่ผู้ใช้อัปโหลด เก็บบนเซิร์ฟเวอร์นี้เท่านั้น แยกตามผู้ใช้
  • เมื่อเจ้าของเพจเชื่อมต่อเพจ Facebook: โทเคนของเพจ (เข้ารหัสก่อนเก็บ), ข้อมูลสาธารณะของเพจ (ชื่อ หมวดหมู่ จำนวนผู้ติดตาม), สถิติรวมของเพจ (Page Insights) และสถิติของโพสต์ที่ระบบโพสต์ (จำนวนรีแอคชัน คอมเมนต์ แชร์ ยอดดู)

ข้อมูลที่ไม่เก็บ

  • ไม่เก็บข้อมูลส่วนตัวของผู้ติดตามเพจหรือผู้แสดงความคิดเห็น (ชื่อ รูป ข้อความส่วนตัว) — ใช้เฉพาะตัวเลขรวม
  • ไม่เก็บ App Secret ของ Meta (ใช้แลกโทเคนครั้งเดียวแล้วทิ้ง) และไม่เก็บรหัสผ่าน Facebook
  • ไม่ส่งข้อความหาผู้ใช้ Facebook คนใด ไม่ซื้อโฆษณา ไม่สร้างบัญชี

การใช้ข้อมูล

ใช้เพื่อเขียนและตั้งเวลาโพสต์บนเพจของเจ้าของเพจเอง วัดผลโพสต์ และแสดงแดชบอร์ดให้เจ้าของเพจเท่านั้น ข้อความทั้งหมดสร้างด้วยโมเดล AI ที่รันบนเซิร์ฟเวอร์นี้ ไม่ส่งข้อมูลไปให้บริการ AI ภายนอก ไม่ขายหรือแบ่งปันข้อมูลให้บุคคลอื่น

การลบข้อมูล

เจ้าของเพจกด "ยกเลิกการเชื่อมต่อ" ในหน้าเพิ่มผู้ติดตามเพื่อลบโทเคนทันที และถอนสิทธิ์แอปได้ที่ Facebook → การตั้งค่า → แอปและเว็บไซต์ ผู้ใช้ลบบทสนทนา ความจำ และไฟล์ของตัวเองได้จากในแอป หรือแจ้งผู้ดูแลเซิร์ฟเวอร์เพื่อลบบัญชีทั้งหมด

Summary (English)

Live AI stores only what its users create (chats, memories, uploads) and, for a connected Facebook Page, the Page's encrypted access token, public Page fields and aggregated Page/post statistics. It never stores followers' personal data, the Meta App Secret or passwords, never messages people, never buys ads, and never sends data to third-party AI services. Disconnecting the Page deletes its token immediately; app permission can be removed in Facebook Settings → Apps and Websites.
